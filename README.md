# أوج لحلول الأعمال — AWJ HUB

الموقع التعريفي للشركة الأم **أوج لحلول الأعمال (AWJ HUB)**: من نحن، خدماتنا،
ومشاريعنا. عربي بالكامل باتجاه RTL، مبني بـ **Next.js 15 + Tailwind CSS 4**.

> مصدر المحتوى: `AWJHUB_introduction_V1.pptx` — الرؤية والرسالة والأهداف
> والخدمات والمشاريع منقولة كما وردت في العرض التقديمي.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح <http://localhost:3000>. للبناء للإنتاج: `npm run build` ثم `npm start`.

> **لا تشغّل `npm install` داخل مجلد Google Drive.** القرص `G:` مجلد Google
> Drive افتراضي بنظام FAT32، وتفشل عليه عملية فك الحزم بخطأ `EBADF`. نسخة
> العمل على قرص محلي: `C:\Users\PCD\Desktop\awj-website`، وGoogle Drive نسخة
> مصدرية للحفظ فقط (بلا `node_modules` ولا `.next`).

## بنية المشروع

```
app/
  layout.tsx      الخط، الميتاداتا، Schema.org، الأيقونات
  page.tsx        ترتيب الأقسام
  globals.css     متغيّرات الهوية وأنيميشن الظهور
components/       كل قسم في ملف مستقل
lib/content.ts    كل النصوص في مكان واحد
public/assets/    الشعارات الرسمية (SVG) وصورة المشاركة
```

ترتيب الأقسام: الهيدر ← الواجهة ← من نحن ← خدماتنا ← مشاريعنا ← لماذا أوج ←
كيف نعمل ← الأسئلة الشائعة ← دعوة للتواصل ← نموذج التواصل ← الفوتر.

## الهوية البصرية

| العنصر | القيمة |
| --- | --- |
| تدرّج العلامة | `#14C48A` ← `#30D9CB` |
| الفحمي (الخلفيات الداكنة) | `#252525` |
| خلفية الأقسام الفاتحة | `#F2F9F6` (رمادي مائل لخُضرة العلامة) |
| لون الحدود | `#DFEAE6` |
| الكحلي (النصوص على الفاتح) | `#142443` |
| ألوان نِصاب الفرعية | `#183552` كحلي، `#B2935C` ذهبي |
| الخط | Tajawal (وزن 600 غير متوفر فيه، فـ`font-semibold` يقع على 700) |

الشعارات في `public/assets` هي ملفات SVG الرسمية منقولة من مجلد الهوية البصرية:

- `awj-ar-*` عربي · `awj-en-*` إنجليزي · `awj-full-*` اللوكاب الكامل
- اللاحقة `-light` للخلفيات الداكنة و`-dark` للخلفيات الفاتحة
- `nsab-light.svg` / `nsab-dark.svg` شعار مشروع نِصاب

أيقونة الموقع (`app/icon.png`) وصورة المشاركة (`public/assets/og.png`) مولّدة
آليًا من هذه الملفات — لإعادة توليدها بعد أي تغيير في الشعار، أعد تصديرها بنفس
المقاسات (512×512 و1200×630).

خلفية الواجهة `public/assets/hero-earth.jpg` صورة الأرض ليلًا (المصدر الأصلي
`unsplash_Q1p7bh3SHj8.png`)، مصغّرة إلى عرض 2000px بجودة 78 لتبقى تحت 210KB.
لاستبدالها بصورة أخرى، صدّرها بنفس المقاس والاسم — لا حاجة لتعديل الكود.

تحتها طبقة `.hero-backdrop` في `globals.css` (تدرّج ليلي بلون العلامة) تظهر
لو غاب الملف يومًا، فلا يبدو القسم مكسورًا — الصورة تغطّيها بالكامل وقت وجودها.

## إمكانية الوصول

الموقع يستعمل حزمة [`accessibility`](https://github.com/ranbuch/accessibility)
(رخصة MIT، بلا اعتماديات) لعرض شريط أدوات عائم أسفل يمين الشاشة:

| الأداة | ما تفعله |
| --- | --- |
| تكبير / تصغير النص | تغيير مقاس كل نص في الصفحة بمقدار 2px لكل ضغطة |
| تباعد الحروف والأسطر | توسيع النص لمن يعاني عسر القراءة |
| عكس الألوان · تدرّجات رمادية | لضعف البصر وعمى الألوان |
| تسطير الروابط | تمييز الروابط دون الاعتماد على اللون وحده |
| مؤشّر كبير · مسطرة القراءة | لصعوبات التتبّع البصري |
| قراءة النص صوتيًا · الإملاء الصوتي | حيث يدعمها المتصفّح (`ar-SA`) |
| إيقاف الحركات | لحساسية الحركة |

الإعداد كلّه في [AccessibilityWidget](components/AccessibilityWidget.tsx):
النصوص العربية، ولغة النطق، واختصارات `Ctrl+Alt+<حرف>` (و`Ctrl+Alt+A` يفتح
القائمة). اختيار الزائر محفوظ محليًا فيبقى بعد إعادة تحميل الصفحة. المكتبة
تُحمَّل ديناميكيًا بعد الإماهة، فلا تدخل حزمة الخادم ولا تؤخّر العرض الأول،
وفشل تحميلها لا يكسر الصفحة.

مظهر الشريط مضبوط على هوية أوج عبر متغيّرات `--_access-*` في نهاية
[app/globals.css](app/globals.css) — لا تُعدَّل أنماط المكتبة مباشرة.

الشريط طبقة فوق أساس سليم لا بديل عنه؛ ما في الكود نفسه:

- حلقة تركيز ظاهرة (`:focus-visible`) بلون `brand-700` — التدرّج الوحيد الذي
  يحقّق 3:1 على الخلفيات البيضاء والفحمية معًا
- `inert` على قائمة الجوال المطويّة وعلى إجابات الأسئلة المغلقة، فلا يصلها
  التنقّل بالكيبورد ولا قارئ الشاشة
- منطقة `role="status"` في نموذج التواصل تُعلن التأكيد عند الإرسال فقط
- إظهار كل الأقسام حين يكون الجافاسكربت مغلقًا (`<noscript>` في `layout.tsx`)
- رفع تباين النصوص الباهتة في الفوتر ونموذج التواصل إلى حدّ WCAG AA

## نظام العناوين

كل قسم يفتح بـ [SectionHeading](components/SectionHeading.tsx): شارة صغيرة
تحدّد القسم، ثم العنوان، ثم شريط بتدرّج العلامة، ثم فقرة تمهيدية اختيارية.
مقاسات العناوين مرتّبة لتبقى المراتب واضحة عند كل عرض شاشة:

| المرتبة | جوال | لوحي | مكتب |
| --- | --- | --- | --- |
| `h1` الواجهة | 40px | 50px | 58px |
| `h2` عناوين الأقسام | 32px | 44px | 52px |
| `h3` عناوين البطاقات | 22px | 22px | 22px |

لا تكتب عنوان قسم يدويًا — استعمل المكوّن ليبقى الفرق بين مرتبة القسم ومرتبة
البطاقة ثابتًا في كل مكان (كان الفارق سابقًا درجة واحدة فبَهُتَ التسلسل).

## الحسابات

كل حسابات التواصل خلف رابط واحد: `site.linktree` في
[lib/content.ts](lib/content.ts) → <https://linktr.ee/awjhub>. زر «كل حساباتنا»
في الفوتر و«@awjhub» في الفوتر ونموذج التواصل كلّها تشير إليه. علامات X
ولينكدإن وإنستغرام داخل الزر زخرفية (`aria-hidden`) تدل على ما خلفه ولا تدّعي
أنها وجهات منفصلة — لتغيير الحسابات، غيّر الرابط في مكان واحد.

## مدة التنفيذ

مدة تسليم الموقع أو التطبيق (**من أسبوعين إلى ٦ أسابيع**) معرّفة في مكان واحد:
`delivery` داخل [lib/content.ts](lib/content.ts). تغييرها هناك يحدّثها في الواجهة
وقسم «كيف نعمل» والأسئلة الشائعة ونموذج التواصل دفعة واحدة.

### ملاحظة عن الأرقام في النص العربي

الشرطة `–` بين رقمين محايدة اتجاهيًا، فتنعكس في فقرة RTL ويظهر `2–6` بصورة
`6–2`. لذلك يُعرض النطاق عبر مكوّن [DeliveryRange](components/DeliveryRange.tsx)
الذي يغلّفه بـ `dir="ltr"`. استخدم المكوّن نفسه لأي نطاق رقمي جديد.

## ما يحتاج تعديلًا قبل النشر

- إضافة مشاريع جديدة إلى مصفوفة `projects` في `lib/content.ts`
- نموذج التواصل في [components/Contact.tsx](components/Contact.tsx) لا يملك خادمًا؛
  يفتح برنامج البريد لدى الزائر بالرسالة جاهزة. لربطه بخدمة فعلية استبدل
  `handleSubmit` بطلب `POST` إلى `app/api/contact/route.ts` أو خدمة خارجية.

## نموذج التواصل

النموذج يرسل إلى [app/api/contact](app/api/contact/route.ts)، والمسار يبعث
الطلب بريدًا إلى `info@awjhub.com` عبر واجهة Resend (`fetch` مباشرة — بلا حزمة
إضافية). للتفعيل انسخ [.env.example](.env.example) إلى `.env.local` أو أضف
القيم في إعدادات Vercel:

| المتغيّر | الغرض |
| --- | --- |
| `RESEND_API_KEY` | المفتاح من resend.com |
| `CONTACT_FROM` | المُرسِل، على نطاق موثّق داخل Resend |
| `CONTACT_TO` | صندوق الاستقبال (افتراضيًا `site.email`) |

**بدون المفاتيح لا ينكسر شيء:** المسار يرد `501`، فيرجع النموذج إلى فتح برنامج
البريد لدى الزائر — وهو سلوكه قبل وجود المسار. وكذلك عند انقطاع الشبكة، فلا
يضيع ما كتبه الزائر في الحالتين.

حالات الرد: `200` نجاح · `400` جسم تالف · `422` اسم أو وسيلة تواصل ناقصة ·
`501` غير مُعدّ · `502` رفَضه المزوّد (يُسجَّل السبب في سجل الخادم). وفيه حقل
`website` مخفي كمصيدة للسبام — أي طلب يملؤه يُقبل صامتًا ولا يُرسَل.

الرد على الطلب يذهب إلى بريد الزائر مباشرة (`reply_to`) متى كتب بريدًا.

## الصور

محسّن صور Next مفعّل في [next.config.mjs](next.config.mjs): كل صورة نقطية
تُقدَّم بصيغة AVIF (أو WebP) وبعرض يناسب شاشة الزائر بدل الملف الكامل.
أثره على خلفية الواجهة:

| الجهاز | العرض المطلوب | المنقول |
| --- | --- | --- |
| الملف الأصلي (قبل التفعيل) | 2000px | 142KB |
| جوال عادي | 384px | 8KB |
| جوال بشاشة مضاعفة | 828px | 26KB |
| مكتب | 1920px | 69KB |

شعارات SVG تحمل خاصية `unoptimized`: هي مُتّجهة أصلًا فلا مكسب من تحويلها،
والمحسّن يرفض SVG ما لم يُفعَّل `dangerouslyAllowSVG` — وتفعيله ليس ضروريًا هنا.

## النشر

كل الصفحات ثابتة (prerendered)، فالمشروع يصلح للنشر على Vercel مباشرة.

للتصدير إلى ملفات ثابتة (`output: "export"`) يلزم إعادة `unoptimized: true`
إلى إعدادات الصور، لأن المحسّن يحتاج خادم Node — وعندها تعود الصور تُرسَل
بحجمها الكامل لكل جهاز.
